# 4분면 자가진단 도구

20개 질문으로 성장의 4분면 위치를 진단하고 다음 단계를 안내하는 React + Vite SPA입니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

빌드 결과물은 `dist/`에 생성됩니다.

## 배포

GitHub Pages용 GitHub Actions 워크플로가 포함되어 있습니다.

1. GitHub 저장소를 생성합니다.
2. 이 프로젝트를 `main` 브랜치로 push합니다.
3. Repository Settings → Pages → Source를 `GitHub Actions`로 설정합니다.
4. push 후 Actions가 완료되면 Pages URL로 공개됩니다.
